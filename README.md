## 🚀 Live Preview & Deployment
To view the portfolio locally:
- Simply double-click `index.html` to open it in any modern web browser.
- Alternatively, run a lightweight local static server:
  ```bash
  npx serve .
  ```
  and visit `http://localhost:3000`.

### Deploying to GitHub Pages (0 Build Steps Required)
1. Create a repository on GitHub (e.g. `Farseen-Ahras.github.io` or `portfolio`) under your account `https://github.com/Farseen-Ahras`.
2. Connect and push your local commits:
   ```bash
   git remote add origin https://github.com/Farseen-Ahras/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.
4. Your website will be live at:
   - `https://Farseen-Ahras.github.io/` (if repo named `Farseen-Ahras.github.io`)
   - OR `https://Farseen-Ahras.github.io/<repo-name>/` (if repo named `portfolio` or other).
