## 🚀 Live Preview & Deployment
To view the portfolio locally:
- Simply double-click `index.html` to open it in any modern web browser.
- Alternatively, run a lightweight local static server:
  ```bash
  npx serve .
  ```
  and visit `http://localhost:3000`.

### Deploying to GitHub Pages (0 Build Steps)
1. Push this repository to GitHub.
2. In your repository, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save** — your site will be live at `https://<your-username>.github.io/<repo-name>/`.
